# Promo images

Marketing images of Apex Overlays, made from the app itself: the overlays and settings window are
the real ones, running against the built-in mock race (so the drivers, track and times are
made up), placed on original backgrounds with the Apex Labs branding. iRacing and Le Mans
Ultimate are named as the games the app works with; no game artwork or footage is used.
